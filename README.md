### Core Engineering Projects

#### ⚖️ [ADOLAT — National LegalTech & Dispute Resolution Platform](https://github.com/mansur20051512/lexHakaton)
- **Stack:** Django 5, Lexical Rule Engine, Tailwind CSS, PyMuPDF, python-docx
- **Highlights:**
  - Automated pre-trial mediation calculator comparing civil litigation costs (2–6 months, 4% state duty) against mediation (3–7 days).
  - Native compliance engine aligned with **2026 Uzbekistan Legal Framework** (BHM standard at 440,000 UZS, MJtK 332-1 15-day 50% discount).
  - Dynamic generation of state-compliant official Word (`.docx`) documents adhering strictly to **O‘zDSt / GOST** bureaucratic formatting standards.
  - Multilingual synchronous state engine supporting Latin Uzbek, Cyrillic Uzbek, and Russian without external dependency lag.

#### 🎙️ [Speech-to-Text — Real-Time Uzbek Acoustic Suite](https://github.com/mansur20051512/Speech-to-text)
- High-accuracy acoustic transcription pipeline optimized for Uzbek phonetics, dialectical nuances, and low-latency audio stream processing.

#### 🔐 [CryptoGen-Pro — Cryptographic Security Suite](https://github.com/mansur20051512/CryptoGen-Pro)
- Mathematical cryptographic workbench implementing asymmetric key generation, entropy verification, and end-to-end data encryption pipelines.

#### 🚁 [dronPochta — Autonomous Routing & Logistics Engine](https://github.com/mansur20051512/dronPochta)
- Algorithmic payload delivery planner utilizing spatial graph routing, autonomous waypoint verification, and logistical telemetry handling.
