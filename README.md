- **Architecture:** Django 5, Lexical Rule Engine, Tailwind CSS, PyMuPDF, python-docx
- **Key Deliverables:**
  - Automated pre-trial mediation calculator comparing civil litigation costs (2–6 months, 4% state duty) against mediation (3–7 days).
  - Native compliance engine aligned with **2026 Uzbekistan Legal Framework** (BHM standard at 440,000 UZS, MJtK 332-1 15-day 50% discount).
  - Dynamic generation of state-compliant official Word (`.docx`) documents adhering strictly to **O‘zDSt / GOST** bureaucratic formatting standards.
  - Multilingual synchronous state engine supporting Latin Uzbek, Cyrillic Uzbek, and Russian.
